# StarCube

离线、单文件的三阶魔方计时器。打开 `starcube.html` 即可练习，无需账号、安装或网络连接。

支持随机状态打乱与魔方展开图、观察计时与提示音、三套高对比主题、训练分组、滚动平均明细、成绩复盘和 JSON 备份提醒。界面适配桌面与手机，数据保存在当前浏览器中。

## 开始使用

1. 下载仓库中的 [`starcube.html`](starcube.html)，用浏览器打开；也可以下载整个仓库后双击该文件。
2. 等待打乱生成。首次打开需要初始化内置求解器，可能耗时数秒。
3. 默认开启观察：按一下空格或轻点计时区开始观察，抬起后再次按住至少 **0.3 秒**，出现 **READY** 后松开开始计时。
4. 计时中按空格或轻点计时区即可停表。成绩自动保存，随后生成下一条打乱。

关闭「观察」后，直接按住至少 0.3 秒，出现 READY 后松开起表。观察罚时按起表瞬间判定：达到 15.000 秒为 +2，达到 17.000 秒为 DNF。

观察提示音默认关闭，可开启后在观察第 **8 秒**听到一声、第 **12 秒**听到两声。独立的试听按钮不影响计时，也不需要开启提示音；声音由浏览器本地生成，无需联网。浏览器不支持或无法播放时，界面会提示。

顶部导航栏右侧提供一键主题切换按钮，可在默认 **纯净纸白**（Studio Light）、**复古暖纸** 和 **极简曜黑** 三套高对比主题之间循环切换，并同步更新页面的 `color-scheme` 与 `theme-color`。主题偏好保存在本机的 `starcube.settings.v1` 中，刷新后自动恢复（不影响观察、提示音和复盘范围偏好，异常值会安全回退默认纸白）。

导出 CSV、导出备份、保存或删除训练组、复制打乱、载入历史打乱和切换主题等操作后，除保留页面原有的状态文案外，界面会在不遮挡计时区的位置弹出约 **2 秒**的柔和轻提示（Toast），并遵循系统的 `prefers-reduced-motion` 设置。

计时页打乱区与成绩详情弹窗均提供「复制打乱」按钮；复制后会给出清晰反馈，浏览器不支持 Clipboard API 或禁止自动复制时会先尝试兼容复制，仍不可用则提示手动选中打乱公式复制。

| 操作 | 快捷键 |
| --- | --- |
| 起停计时 | 空格 |
| 换一条打乱 | `N` |
| 切换最新成绩 +2 | `1` |
| 切换最新成绩 DNF | `2` |
| 取消观察 | `Esc` |

删除最新成绩使用界面按钮；也可以打开任意历史成绩详情，点击「删除这条成绩」。删除后会显示「撤销删除」，可按相反顺序撤销本页的多次删除，恢复原成绩、罚时与所属训练。撤销入口保留到当前页面关闭或刷新，普通备份导入不会自动恢复尚未撤销的删除。输入框和选择框内的操作不会触发计时快捷键。

## 训练与复盘

- **训练组**：新建、切换、重命名或删除训练（默认训练 `default` 不可删除）。每组有独立的成绩、统计和历史；全局 PB 汇总所有训练组。删除空训练组会直接移除并切回默认训练；如果训练组内包含成绩，会弹出二次确认窗口，明确提示包含的成绩条数并支持先一键导出 JSON 备份。删除后安全切回默认训练组，统计、历史、趋势图与跨标签页存储同步更新，且不留脏数据。
- **统计**：Ao5、Ao12、Ao50、Ao100、当前训练平均、单次 PB 和最佳 Ao5。AoN 从两端各去掉 5% 的成绩（向上取整）；+2 计入用时，去尾后仍有 DNF 则该平均为 DNF。
- **平均值明细**：点击 Ao5 或 Ao12，查看最近 N 次的有效用时、去掉的最快与最慢成绩，以及保留项的总和与平均值。点击明细中的成绩可打开单次详情，修改罚时后通过「返回明细」回到原窗口，计算结果随之更新。从计时页打开的各层明细均可点击「继续计时」，直接回到计时区，保留当前训练与打乱，不自动起表。鼠标或触摸关闭最外层明细也会回到计时区；键盘关闭与 Esc 保留正常返回焦点。
- **复盘**：查看最近 50 或 100 次的单次与 Ao5 趋势，查看单次详情，修改历史成绩的正常 / +2 / DNF 状态，或删除并撤销。单次详情支持「复制打乱」以及「用这条打乱再测一次」——点击后会关闭详情弹窗、切回计时页并将当前打乱与展开图替换为该条打乱（保持原有起表与防误触边界，不自动起表）。详情里的「截至该次 Ao5」可打开相应历史窗口；返回时保留浏览位置。
- **日期与对比**：在复盘范围中选择「今天」或「最近 7 天」。今天对比昨天；最近 7 天包含今天，对比之前紧邻的 7 个自然日，均按设备本地日期计算。显示两期练习次数、有效平均、成绩波动（总体标准差）与 DNF 比例及变化。当前时段截至现在，尚未结束；有效成绩不足 5 次会提示样本较少，不足 2 次不计算波动。平均与波动排除 DNF，+2 计入；DNF 比例以全部次数为分母。
- **日期范围说明**：日期筛选同时作用于趋势、对比和历史成绩；本组统计仍包含整个训练。日期历史按日分段，保留原成绩编号，可通过「查看今天／最近 7 天的成绩」直接展开并跳转。历史可分批加载该时段全部成绩；「全部历史」切回最近 50 次趋势与本组全部历史。对比统计使用所选期间全部成绩，超过 100 次时曲线只显示最近 100 次；各点 Ao5 仍使用本组截至该次的最近 5 把，可能跨越日期边界。页面在前台按分钟更新日期范围，跨午夜或回到页面时自动刷新，趋势折叠时历史仍会更新。
- **范围偏好**：记住上次选择的「今天／最近 7 天／最近 50 次／最近 100 次」。重开页面仍先进入计时页，进入复盘后使用保存的范围；日期按打开时的本地时间重新计算。
- **最佳成绩追溯**：本组 PB、全局 PB 和最佳 Ao5 均可点击查看对应成绩或组成的五把。全局 PB 可跨训练查看、编辑，不会切换当前训练；同分最佳 Ao5 定位最早的窗口。
- **历史与导出 CSV**：按需展开，每次加载 50 条。按次数复盘时显示本组全部历史，按日期复盘时显示对应时段的历史。修改罚时、删除和撤销后列表与对比同步更新。历史头部提供「导出 CSV」按钮，导出当前训练组在当前筛选范围内的全部成绩（不受 50 条分页或图表 100 点截断限制），顺序与历史列表一致（最新在前），包含记录时间、原始用时、状态（正常、+2、DNF）和打乱公式；文件带 UTF-8 BOM 与 CRLF 换行，方便 Excel 直接打开且中文不乱码。导出 CSV 不替代全量 JSON 备份，也不会重置备份提醒。

## 数据与备份

成绩使用当前浏览器的 `localStorage` 保存，没有账号或云同步。更换浏览器、打开方式或文件位置后，原记录可能不可见；清理浏览器数据也可能移除记录。移动文件或更换设备前，先用「导出」保存 JSON 备份。

「导出」包含全部训练组、成绩及可恢复的原始备份。「导入」合并并去重，不直接覆盖现有记录；支持旧版成绩数组以及 StarCube v2 / v3 备份，单个文件上限为 10 MiB。

全部训练组的成绩自上次导出或选择「稍后提醒」起净新增 **100 条**后，会出现备份提醒；首次使用该提醒功能时，已有至少 100 条成绩也会提醒。导出只表示浏览器已发起下载，无法确认文件是否落盘，请检查下载结果。

当浏览器禁止存储或写入失败时，页面会提示并保留内存中的记录。此时请及时导出，避免关页后丢失未保存的成绩。

## 项目结构

```text
starcube.html             可直接打开的完整应用
src/                     页面模板、应用逻辑、统计、存储和求解器
scripts/                 构建、测试及求解器同步入口
tests/                   本地回归测试
  browser/               浏览器回归测试
  fixtures/              旧版存储迁移夹具
docs/                    开发与验证说明
THIRD_PARTY_NOTICES.md    第三方代码许可
```

开发时修改 `src/`，再构建 `starcube.html`。浏览器配置、测试下载、截图和本地历史档案不进入 Git；测试结果写入 `test-results/`。本机已有的开发历史另存于被忽略的 `.local/`。

## 构建与测试

开发工具需要 **Node.js 22 或更高版本**。构建和测试仅使用 Node.js 内置模块，无需运行 `npm install`。

```sh
npm run build
npm test
```

也可以直接运行：

```sh
node scripts/build.cjs
node scripts/test.cjs --report
```

本地测试覆盖统计与平均明细、观察提示音、备份提醒、复盘模型、存储与迁移、打乱求解、计时状态和单文件构建一致性。浏览器测试的运行方法与验证范围见 [开发与验证说明](docs/DEVELOPMENT.md)。

只有修改 `src/worker-entry.js` 后，才需要先运行 `npm run sync-solver`，再重新构建和测试。该命令同步 Worker 入口，保留现有 cubejs 依赖部分。
